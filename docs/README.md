# Lucent Docs

This directory owns backend-specific documentation. Keep the root README short and link here for details.

## Files

- `api-contract.md`: versioning, envelope shape, errors, headers, and JWT identity rules.
- `data-sources.md`: external data source boundaries and import ownership.
- `environment.md`: SWC, env files, script modes, and current app bootstrap baseline.
- `migration-roadmap.md`: phased backend buildout from Nest starter to production Lucent.

## Boundaries

- Luminous docs describe Flutter/client migration and project coordination.
- Lucent docs describe backend protocol, database, import, deployment, and module plans.
- The deprecated Express backend under `Luminous/backend` is reference material only.
