## fix(config): OPENAPI_EXPORT_SKIP_REDIS 走 EnvKey 类型化并补 env 声明与模板

按 `plans/Lucent-review-09-05.md`（实施完毕文件已删）W2 落实:

- `src/config/env/env-keys.enum.ts` 补 `OPENAPI_EXPORT_SKIP_REDIS` 枚举成员。
- `throttler.config.ts`、`cache.config.ts`、`queue.factory.ts`、`redis.service.ts` 共 4 处
  `configService.get<string>('OPENAPI_EXPORT_SKIP_REDIS')` 字符串字面量改用
  `EnvKey.OPENAPI_EXPORT_SKIP_REDIS`，重命名/删除该 env 时 IDE 会报红。

  `(key: string)`，改 `EnvKey` 会触发 oxlint `no-dynamic-delete` / eslint
  `no-unsafe-enum-comparison` 双 lint 规则，保持字符串字面量（测试 mock 语义无类型收益）。
- `.env.development.example` 与 `.env.test.example` 的 "OpenAPI 导出" 段落补
  `OPENAPI_EXPORT_SKIP_REDIS=false`（此前只有 DB_CONNECT）；`.env.production.example`
  不涉及（export 标志仅用于开发/CI 导出流程）。
- `docs/reference/environment-variables.md` 新增 "Build / export flags (internal)" 章节，
  记录 `OPENAPI_EXPORT_SKIP_DB_CONNECT`（`prisma.service.ts` 消费）与
  `OPENAPI_EXPORT_SKIP_REDIS`（throttler/cache/queue/redis 消费）两个由
  `export-openapi.ts` 编程式设置的导出期标志；`updated` 前移至 2026-09-06。
