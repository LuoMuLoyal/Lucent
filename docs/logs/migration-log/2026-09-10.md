## feat(entrypoint): 容器启动时自动执行 prisma migrate deploy

新增根目录 `entrypoint.sh` 作为容器启动入口,替代 `CMD ["node", "dist/main.js"]`:

- 启动前执行 `node_modules/.bin/prisma migrate deploy`(数据库迁移),失败按指数
  重试(`MIGRATE_MAX_RETRIES` / `MIGRATE_RETRY_DELAY` 可调),最终失败则退出——
  绝不在 schema 未就绪时带病启动应用。
- 迁移成功后 `exec node dist/main.js`(exec 使 node 成为 tini 直接子进程,
  信号转发与僵尸回收语义与旧 ENTRYPOINT 一致)。

意义:Coolify 侧不再需要 Pre-deployment command 手动配置迁移;容器每次启动
自动保证 schema 最新。文档(howto/deploy.md、reference/deployment.md)同步
更新发布流程:迁移步骤改为「容器启动时自动执行」,移除手动 docker exec 迁移。
的 Pre-deployment command 配置说明。

验证:`docker build` 通过;`docker compose config` 通过。
