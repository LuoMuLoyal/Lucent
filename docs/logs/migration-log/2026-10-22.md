# 2026-10-22

## fix(ci): 修复三仓 CI 失败（Scorecard / CodeQL / Docker / e2e）

- **Scorecard（Lucent / Luminous / Luminary 三仓同因）**：`push.branches` 原本含
  `develop`，而 `scorecard-action` 只接受默认分支，非默认分支上以
  `validating options: only default branch is supported` 直接失败。三仓均收窄为
  `branches: [main]`；`schedule` 本就只跑默认分支，`branch_protection_rule` 不受影响。
- **CodeQL（Luminary）**：Rust 提取器不支持 `autobuild`，`database init` 阶段 fatal
  （`Rust does not support the autobuild build mode`）。矩阵中 rust 行改为
  `build-mode: none`；JS/TS 行本就是 `none`，`security-extended` 查询集不变。
- **Docker（Lucent）**：三个 stage 都用 `corepack enable`，corepack 会在每次
  `pnpm ...` 时临时下载 pnpm 二进制；arm64 走 `@pnpm/exe.linux-arm64-musl`，
  30 秒超时即整个 build 失败。改为 `npm install --global pnpm@12.0.0`（与
  `package.json#packageManager` 对齐），走 npm 自身的重试与缓存。
- **CI e2e（Lucent）三个既有失败**：
  - `startup-order`：`BullmqQueueFactory` 新增第三构造参数 `QueueRuntimeRegistry`，
    测试 providers 未同步。补齐 provider（registry 的 `RuntimeConfigService` 是
    `@Optional()`，无需再提供）；同时把 `afterAll` 的清理改为按 `moduleReady` 标志
    判断——原来 `compile()` 失败后 `moduleRef` 为 undefined，清理时的二次异常会把
    真实 DI 错误盖成 `Cannot read properties of undefined (reading 'close')`。
  - `admin-metrics`：夹具只有 4 个 core 事件，低于 `MIN_FUNNEL_GROUP_SIZE`（10），
    小样本守卫会置 `detailsSuppressed: true` 且 `daily: []`。测试却同时断言
    `detailsSuppressed: false` 与非空 `daily`，两者自相矛盾。改为断言真实抑制语义，
    并注明 totals 仍可见。
  - `openapi-metadata`：5 个 admin 响应 schema 缺 `example`/`nullable`。开放的
    `z.record(...)` 既无属性也无 `$ref` 可借元数据，故给 `adminResourceRowSchema`
    加 `example`，并给列表/关联响应的标量字段补 `example`。`pnpm export:openapi`
    重新生成后契约测试通过。
  - 顺带修 `admin-data` 审计用例：`findFirst` 未按本次创建的行走过滤，会命中历史
    或兄弟用例写入的审计记录；改用响应里的 `resourceId` 精确定位。
- **CI（Luminous）**：`flutter analyze` 会分析 `pkgs/` 下的源码，但根 `pub get`
  不会为 path 依赖的子 package 各自解析依赖。`pkgs/luminous_native_bridge/pigeon/`
  引用了只在其 `dev_dependencies` 里的 pigeon，干净 clone 上以
  `Target of URI doesn't exist: 'package:pigeon/pigeon.dart'` 失败（本地能过是
  之前手动跑过 `pub get`）。CI 增加「Resolve sub-package dependencies」步骤，
  对两个 Flutter 子包跑 `flutter pub get`。
- 验证：`pnpm typecheck`、`pnpm lint:check`（0 error）、`pnpm test:e2e:ci` 全通过；
  `pnpm export:openapi` 已重生成；Luminous `flutter analyze` 无 issue，两个子包
  `flutter pub get` 成功。
