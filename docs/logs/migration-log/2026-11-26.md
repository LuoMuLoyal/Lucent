# 2026-11-26

## ci(lucent): OpenAPI 契约漂移校验后移到 E2E 之后

### 变更范围

`.github/workflows/ci.yml` 的 `e2e` job 里，`Verify OpenAPI spec is committed` 原本排在
`E2E tests` **之前**。前者的全部内容是一次 `git diff --exit-code --
docs/reference/generated/openapi.json`，与 E2E 套件之间没有数据依赖：E2E 只需上一步
`Export OpenAPI spec` 产出的文件（读的是工作区现成那份），不关心它与 HEAD 是否一致。

排在前面的后果是：一次「改了 DTO 但忘了提交 openapi.json」会让整轮 E2E 白跑，
报错也停在契约漂移上，看不到测试本身的结论。两件事都是真问题，但只有一件是当轮改动的
直接产物，另一件是既存事实，应该都能看到。

改为：

```
Build → Export OpenAPI spec → E2E tests → Verify OpenAPI spec is committed
```

`Export` 仍在 `E2E` 之前（契约测试套件启动时加载 `openapi.json`），这一点没动。

### 顺带清理

`34680219 chore(ci): 撤下 Go 契约校验 job` 中删除，注释却留在原处，指向不存在的 job。
已删除。
