- `src/app.dto.ts` 迁移为 zod（`healthCheckResultSchema` 等，原生 `.meta({ example })` 过 §二-3 门禁）；

  `ResponseSchemaRegistration.errorStatuses` 并在 `export-openapi.ts` 据此把 503 也 `$ref` 到
  `HealthResponse`（原 class 方案靠 `@ApiResponse({ status: 503, type })` 直出）。
- 清理：`src/app.service.ts` 已无裸 `throw new Error`，从 `eslint.config.ts` 的豁免名单删除；
