# 2026-10-29

## build(node): 对齐 Node 26 LTS（Lithium）并收敛版本声明面

Node.js 26 于 2026-10-28 进入 Active LTS（代号 Lithium），首个 LTS 版本为 **26.13.0**。
此前仓库的四个版本声明面（`engines` / `.node-version` / CI / Dockerfile）已经由
2026-10-03 那次收敛到 `.node-version` 单一事实源，本次只需把 patch 追平到 LTS 首发版。

### 变更

- `.node-version`：`26.9.0` → `26.13.0`。CI 三个 job 均以 `node-version-file: .node-version`
  引用，无需逐个改动。
- `Dockerfile`：四阶段 `node:26.11-alpine` → `node:26.13-alpine`（deps / builder /
  admin-console / production）。此前 Dockerfile 由 Dependabot 独立维护，落后于
  `.node-version`；本次一并追平，避免镜像与 CI 落在不同 patch 上。
- `engines.node` 保持 `>=26 <27`：范围已覆盖 26.13，无需改动。

### 验证

本地系统级 Node 升级到 26.13.0 后实跑：`pnpm install --frozen-lockfile` 通过；
`pnpm typecheck` 无报错；`pnpm build`（SWC）编译 913 文件成功；`pnpm lint:check`
0 error（2 条既有 warning，与本次升级无关）。

环境侧记录：Node 26 起不再捆绑 corepack，pnpm 12.0.0 为 `npm i -g` 独立安装，
升级后 `pnpm -v` 正常；未引入新的原生模块 ABI 依赖面（`@swc/core` 的
`win32-x64-msvc` 预编译产物在 26.13 下正常加载）。
