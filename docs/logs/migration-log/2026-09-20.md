### 背景

对 Lucent 根 README 做了一次事实核对，发现它落后于已经落地的检索与推理分层：
`Key Features` 仍写"三个独立向量检索源"，没有体现英文侧 OAG、LightRAG 中文散文检索、
Apache AGE 图后端；`Stack` 仍写 PostgreSQL / Prometheus，未反映 pgvector + AGE 自建镜像
与 VictoriaMetrics；`dev:stack` 说明仍描述为纯 `pgvector/pgvector:pg18`，而实际镜像已是
叠加 AGE 的自建 `lucent-db:18`（`docker/postgres-age/`），且图数据落在独立 database
`lucent_graph`。另外发现三处指向已不存在路径的引用。
