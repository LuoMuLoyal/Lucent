## SyncWorker 重放 dose log mark 请求 VALIDATION_FAILED 修复

### 问题根因

SyncWorker 重放因网络失败而入队的 `POST /api/v1/user/medicine-dose-logs/mark` 请求时，后端返回 `VALIDATION_FAILED`（400）。通过 Jaeger trace 追查到 `MedicineDoseLogsController.mark` → `doseLogsService.mark` 中第 144-151 行的验证逻辑：

当 `reminderId == null`（临时打卡）时，`buildMarkLookupWhere` 返回 `null`，随后检查 `where == null && (reminderId != null || currentMedicineId == null || scheduledTime == null)`。临时打卡合法地可以没有 `reminderId` 和 `scheduledTime`，但原逻辑会因为 `scheduledTime == null` 而拒绝请求。

### 修复

- `src/modules/medicine-dose-logs/services/dose-logs.service.ts`：当 `where == null`（无 reminder）时，只检查 `currentMedicineId == null`，不再检查 `scheduledTime == null`。
- `src/modules/medicine-dose-logs/services/dose-logs.service.spec.ts`：原测试 "should reject mark when currentMedicineId is provided without scheduledTime" 改为 "should create mark when currentMedicineId is provided without scheduledTime (temporary log)"，验证临时打卡在没有 `scheduledTime` 时能成功创建。

## 药品详情页 CheckedFromJsonException 修复 — DrugBank 列表字段标记为可选

### 问题根因

药品详情页（`GET /api/v1/medicines/:id?source=cn`）一直显示骨架屏。前端日志显示 `CheckedFromJsonException: Could not create MedicineDetailResponseDtoDetail. Required keys are missing: groups, categories, atcCodes, synonyms, foodInteractions`。

后端 `DrugbankMedicineDetailDto` 中 `groups`、`categories`、`atcCodes`、`synonyms`、`foodInteractions` 使用 `@ApiProperty`（非 optional），OpenAPI spec 将它们标记为 required。生成的 Dart DTO 用 `required: true, includeIfNull: false` + `@JsonSerializable(checked: true)`，当 CN 药品详情 JSON 不包含这些 DrugBank 专有字段时，`fromJson` 抛出 `CheckedFromJsonException`。异常被 generated API 包装成 `DioException(unknown)`，`ErrorInterceptor` 试图按 Problem Details 解析但 Content-Type 是 `application/json` 而非 `application/problem+json`，抛出 `FormatException` 逃逸，导致 Riverpod `AsyncValue` 一直处于 loading 状态。

### 修复

- `src/modules/medicines/dto/detail.dto.ts`：`groups`、`categories`、`atcCodes`、`synonyms`、`foodInteractions` 从 `@ApiProperty` 改为 `@ApiPropertyOptional(nullable: true)`，类型从 `string[]` 改为 `string[] | null`。
- 重新导出 OpenAPI spec（`pnpm export:openapi`），重新生成 Flutter 客户端（`dart run scripts/bootstrap_generated_sources.dart`）。
- `Luminous/lib/features/medicine/data/mappers/medicine_detail.dart`：`detail.groups` 等改为 `detail.groups ?? const []` 处理 null。
