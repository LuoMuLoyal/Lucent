## feat(medicines): 新增专利 / 属性 / 通路 / 反应链 / SNP / 分子指纹六类数据导入

- 数据落库形态按 PRODUCT.md §3 的查询方式决定，新增三个模型 + 四个 jsonb 字段：
  - `DrugbankPatent`（`drugbank_patents`）：专利悬崖按到期日范围查询，jsonb 无法索引，
    故建表；唯一键 `(drugbank_id, patent_number, country)`，`expires_on` 建索引。
  - `DrugbankProperty`（`drugbank_properties`）：同一属性有多个来源且需数值比较，
    故建属性表；`value_text` 保留原文，`value_num` 仅在能无歧义解析时填充，
    `is_experimental` 区分实测与模型预测（ALOGPS / ChemAxon）。
  - `DrugbankFingerprint`（`drugbank_fingerprints`）：2048-bit Morgan 指纹存 512 位
    十六进制串，Tanimoto 走 SQL 精确计算。未用 pgvector 距离算子——余弦 / L2 /
    内积 / 汉明均不等于 Tanimoto，且 1.5 万分子顺序扫描已足够。
  - `drugbank_drugs` 新增 `pathways` / `reactions` / `snp_effects` /
    `snp_adverse_effects` 四个 jsonb 列：只按药取整块，覆盖率 0.4%–3.3%，不值得建表。
- 迁移 `20261021220000_add_drugbank_patents_properties_fingerprints` 已 deploy 到 dev
  （15432）。dev 库存在与迁移目录不一致的历史 drift（`cn_medicine_products`
  额外索引、索引重命名、孤儿 checkpoint 表等），本次只手工摘出与本变更相关的 DDL，
  未走 `prisma migrate dev`。
- 解析器（`scripts/import/medicine/parsers/`）：
  - `drugbank_nested.py`：统一处理 parquet 内嵌 JSON 的「单对象 / 数组」混用形态。
    源数据同一列在不同行分别给出 bare object 与 array（`patents` 单对象 204 行、
    数组 330 行），只按一种形态解析会静默丢行。
  - `drugbank_patents.py` / `drugbank_properties.py` / `drugbank_json_blocks.py` /
    `drugbank_fingerprints.py`，均通过 `--limit` 按**源文件行**计数，与既有命令一致
    （按输出行计数会让覆盖的药物集合与父导入错位，触发外键失败）。
  - jsonb 解析器额外输出 `name`：upsert 是整行 INSERT，而 `drugbank_drugs.name`
    为 NOT NULL；`name` 不在 `updateColumns` 内，不会覆盖既有名称。
  - `drugbank_fingerprints.py` 依赖 RDKit（仅导入期使用，运行时无依赖）。
- `db-upsert.ts` 支持 `config.parserArgs` 透传解析器专用参数（同一 parquet 的多列导入），
  并新增 `PYTHON_BIN` 环境变量指定解释器——解析器依赖装在项目 venv 里，
  PATH 上的 `python` 未必有 `pyarrow` / `rdkit`。
- `import-medicine-datasets.ts` 补 9 个命令到白名单与全量顺序（外键要求药物先入库）。
