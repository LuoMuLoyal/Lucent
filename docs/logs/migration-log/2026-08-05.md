# 2026-08-05 全仓库审查修复

## 按 `plans/Lucent-review-2026-08-05.md` 修复

本轮修复针对 2026-08-05 全仓库审查中的 2 个 🔴 严重问题与 3 个 🟡 警告项。

### `isQueueConnectionError` 正则匹配收紧（🔴 #1）

- `src/common/helpers/infra/queue-helpers.ts`
  - 移除 `/Connection/i`、`/Redis/i`、`/socket/i`、`/timeout/i` 等过于宽泛的正则模式，
    避免业务错误（如 `"Redis transaction failed: invalid data format"`）被误判为连接错误
    而静默走 fallback 路径。
  - 新增 `CONNECTION_ERRNO_CODES` 集合，优先通过 `error.code` 精确匹配 errno 代码
    （`ECONNREFUSED`、`ECONNRESET`、`ETIMEDOUT`、`ENOTFOUND`、`EAI_AGAIN`、`EPIPE`、
    `EHOSTUNREACH`、`ENETUNREACH`）。
  - 保留窄化的消息模式 fallback（`/connection (?:refused|reset|lost|closed|terminated|timed out|ended|dropped)/i`、
    `/socket (?:hang up|closed|destroyed|ended)/i`），用于没有 `.code` 属性的包装错误。
- `src/common/helpers/infra/queue-helpers.spec.ts`
  - 新增 errno-coded 错误回退、业务错误不误判（Redis transaction failed / generic timeout）用例。

### `respondCache.set` 缓存操作日志（🔴 #2）

- `src/modules/assistant/agent/runtime.service.ts`
  - `respondCache.set` 方法新增 `this.logger.debug` 调用，记录 key 前缀（截断至 60 字符）和 TTL，
    提供缓存写入的审计追踪能力。

### 魔法数字 6379 命名化（🟡 #3）

- `src/common/helpers/infra/redis-url.ts`
  - 提取 `const REDIS_DEFAULT_PORT = 6379`，替代裸数字。

### 重复 `hashKey` 函数消除（🟡 #4）

- 新增 `src/common/helpers/infra/hash.utils.ts`
  - `makeShortHash(value, length = 16)`：统一的短哈希缓存键生成函数。
  - 附带 `hash.utils.spec.ts`（6 个测试用例）。
- `src/modules/assistant/agent/runtime/respond.ts`
  - 移除本地 `hashKey` 函数，改用 `makeShortHash`。
- `src/modules/assistant/tools/tool.service.ts`
  - 移除内联 `createHash('sha256').update(...).digest('hex').slice(0, 16)`，改用 `makeShortHash`。
- `src/common/index.ts`
  - 导出 `makeShortHash`。

### `enqueueOrFallback` 接受可选 logger 参数（🟡 #5）

- `src/common/helpers/infra/queue-helpers.ts`
  - `enqueueOrFallback` 新增可选 `logger?: Logger` 参数，传入时使用实例 Logger（可 DI 替换、
    测试可 mock），未传入时回退到静态 Logger。
- `src/modules/reports/reports.controller.ts`
  - 两处 `enqueueOrFallback` 调用传入 `this.logger` 实例。
- `src/common/helpers/infra/queue-helpers.spec.ts`
  - 新增 logger 实例被正确调用的测试用例。
