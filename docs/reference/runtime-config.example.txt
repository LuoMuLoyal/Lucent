################################################################################
#  Lucent — 运行时调优文档
################################################################################
#  这是**唯一**一份可以在不重启进程的前提下改掉下面这些值的文档。
#
#  坐标（rnacos 控制台三处）：
#    namespace = lucent-dev | lucent-test | lucent-prod
#    group     = LUCENT_RUNTIME
#    dataId    = lucent-runtime-tuning.txt
#    类型      = text（服务端不解析内容）
#
#  格式：`.env` 的子集 —— 同一个键名、同一种写法（`KEY=value`），一行一个键。
#  只有本文件列出的键允许出现；这份文件就是完整白名单。
#
#  语义（三条，必须记住）：
#    1. 空值（`KEY=`）与「不写这个键」等价：沿用环境变量 / 代码基线，
#       不会被置成 0 或空串。下面的活行都写成各键的代码默认值，
#       于是照抄发布不会改变任何行为。
#    2. 未知键、重复键、越界值、版本不符 → **整份拒绝**。进程继续用上一版
#       快照，日志里给拒绝原因（只含键名，不含值）。改错一个键 = 整份不生效。
#    3. **删除配置不是回退手段**：删除后该 dataId 不再推送。回退一律是
#       「发布一个新版本」（把值改回默认，或把 `RNACOS_REVISION` 往前推）。
#
#  这里永远不会有：密钥、连接串、provider 开关、只在启动时读取的项
#  （`DATABASE_URL`、`JWT_*_SECRET`、`*_API_KEY`、`AI_*_API_KEY` …）。
#  那些仍然是 `.env` 的职责；把它们贴进来只会让整份文档被拒绝。
#
#  每个键上方的注释说明：它配置什么、单位与取值范围、默认值、什么时候该改。
################################################################################
