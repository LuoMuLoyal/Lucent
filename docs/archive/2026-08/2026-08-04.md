# 2026-08-04 增量代码审查修复

## 按 `plans/Lucent-review-2026-08-04.md` 修复（实施完毕文件已删）

本轮修复针对 2026-08-03 增量审查中的 3 个 🔴 严重问题与 4 个 🟡 警告项。

### `parseRedisUrl` 输入验证与 IPv6 处理

- `src/common/helpers/infra/redis-url.ts`
  - 新增输入校验：空字符串 / `null` / `undefined` 与非法 URL 抛出带业务上下文的错误
    (`Invalid Redis URL: "..."`)，避免 `new URL()` 原生 `TypeError` 在启动时难以定位。
  - 仅允许 `redis://` / `rediss://` scheme，其它 scheme 给出明确错误。
  - IPv6 hostname 去除 URL 方括号：`new URL('redis://[::1]:6379').hostname` 返回 `"[::1]"`，
    替换为 `"::1"` 以兼容 ioredis / BullMQ。
- `src/common/helpers/infra/redis-url.spec.ts`
  - 新增 IPv6、非法 URL、空字符串、错误 scheme 用例。

### `streamModelResponse` `onText` 异常隔离

- `src/modules/assistant/agent/runtime/model-stream.ts`
  - `await onText(text)` 包裹 try-catch：SSE 客户端断开、网络抖动等传输层异常不再中断
    流式聚合，继续收集最终 `AIMessage`；错误通过 `Logger.error` 记录。
- `src/modules/assistant/agent/runtime/model-stream.spec.ts`
  - 新增 `onText` 抛错时仍继续聚合最终文本的用例，并断言日志输出。

### 共享内容提取函数

- 新增 `src/modules/assistant/agent/runtime/message-text.utils.ts`
  - `extractMessageText(content)`：统一处理 `string` 与 content-part 数组，提取 `part.text`。
- `src/modules/assistant/agent/runtime/model-stream.ts`
  - 移除内联 `readChunkText`，改用 `extractMessageText`。
- `src/modules/assistant/agent/runtime/nodes.ts`
  - 移除 agent 节点内重复内容提取逻辑，改用 `extractMessageText`。
- `src/modules/assistant/agent/runtime/respond.ts`
  - `extractContent` 简化为 `extractMessageText` 调用。

### `enqueueOrFallback` 宽泛 catch 修复

- `src/common/helpers/infra/queue-helpers.ts`
  - 新增 `isQueueConnectionError` 守卫：仅当错误为 Redis/网络相关（`ECONNREFUSED`、
    `ECONNRESET`、`ETIMEDOUT`、`ENOTFOUND`、`EAI_AGAIN`、`EPIPE`、Connection/Redis/socket/
    timeout 关键字）时才走同步 fallback。
  - `TypeError` / `ReferenceError` / `SyntaxError` 等编程错误继续抛出，避免隐藏真实 bug。
- `src/common/helpers/infra/queue-helpers.spec.ts`
  - 新增编程错误不被吞咽、直接抛出的用例。

### Reminder 去重迁移性能优化

- `prisma/migrations/20260803120000_reminder_delivery_dedup_unique/migration.sql`
  - 删除 O(n²) 的 `DELETE ... USING` 自连接。
  - 改为 `ctid + ROW_NUMBER() OVER (PARTITION BY user_id, reminder_id, scheduled_for ORDER BY created_at)`
    CTE，仅删除重复行中 `created_at` 较晚的记录，降低大表迁移锁表与超时风险。

### `setup-app.ts` 模块级同步文件读取修复

- `src/setup-app.ts`
  - 移除模块加载时通过 `readFileSync` 读取 `package.json` 的 IIFE。
  - 新增异步 `resolveScalarStandaloneUrl()`：优先读取 `SCALAR_API_REFERENCE_VERSION` 环境变量，
    回退到 `setupApp` 内部读取 `package.json` 解析 `@scalar/api-reference` 版本号。
  - 在 `setupApp` 内 `await` 解析结果后传入 Scalar `cdn` 配置。
- `docs/01-reference/environment-variables.md`
  - 新增 `SCALAR_API_REFERENCE_VERSION` 可选环境变量说明。
