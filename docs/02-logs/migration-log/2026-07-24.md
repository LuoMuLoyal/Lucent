# Migration Log — 2026-07-24

## 代码审查修复：事务安全、资源管理、错误可观测性

### P0 — 严重问题修复

1. **Token 生成与会话创建顺序调整** (`src/modules/auth/services/token.service.ts`)
   - 调整 `generateTokenPair` 操作顺序：先创建 session 记录，再签发 JWT。
   - 防止 JWT 签发成功但 session 未入库导致用户拿到无法刷新的 accessToken。
   - 增加 JWT 签发失败时的 error 日志。

2. **用药提醒调度器消息丢失修复** (`src/modules/medicine-reminders/services/scheduler.service.ts`)
   - 调整 `dispatchSingle` 操作顺序：先发送通知，成功后再创建 delivery 记录。
   - 通知失败时不会创建 delivery 记录，下次调度会自动重试。

3. **OAuth 通知失败日志补全** (`src/modules/auth/services/oauth/facade.service.ts`)
   - `linkWechatWebIdentity` 和 `loginWithOAuthProfile` 中的通知 catch 块从静默吞掉改为输出 warn 日志。
   - 记录 userId 和错误详情，保持非阻塞行为。

### P1 — 警告问题修复

4. **LLM Stream 资源泄漏修复** (`src/common/llm/base-llm-generator.service.ts`)
   - `generateStream` 中增加 `lastStream` 引用跟踪，重试失败时尝试调用 `return()` 清理 stream。
   - 防止高并发场景下 HTTP 连接池耗尽。

5. **argon2 验证异常日志补全** (`src/modules/auth/services/account.service.ts`)
   - `argon2.verify` 的 catch 块从静默吞掉改为输出 warn 日志。
   - 记录 userId 和错误详情，便于发现底层基础设施问题。

### P2 — 改进项修复

6. **数据导出错误信息泄露修复** (`src/modules/data-export/services/processor.service.ts`)
   - catch 块中 `throw error` 改为 `throw new Error('Export processing failed for request ...')`。
   - 避免原始异常详情（文件路径、数据库错误等）泄露到非 HTTP 上下文。

7. **建议引擎降级标记** (`src/modules/today-suggestion/dto/suggestion-history.dto.ts`, `src/modules/today-suggestion/services/suggestion.service.ts`)
   - `TodaySuggestionsDataDto` 新增可选 `degraded` 字段。
   - 规则执行异常时设置 `degraded: true`，前端可据此显示"建议可能不完整"提示。

8. **Prisma 嵌套事务检测** (`src/modules/daily-records/repositories/daily-record.repository.ts`)
   - `transaction` 方法增加 `AsyncLocalStorage` 嵌套检测。
   - 嵌套调用时输出 warn 日志，提醒开发者修正调用方。

## Barrel 导出模式重构

按照 `plans/2026-07-24-barrel-cleanup.md` 执行了全量 barrel 导出重构，共 6 个阶段：

### 阶段 1+2 — 删除所有子目录 barrel（109 个）

- 删除 `src/modules/` 和 `src/admin/` 下所有子目录 `index.ts` barrel（services/、dto/、types/、constants/ 等）
- 214 个消费者文件改为深路径导入（如 `from './services/account.service'`）
- 消除了 51 个单导出 barrel 和 ~58 个多导出 barrel

### 阶段 3 — 创建模块根 barrel，统一跨模块导入

- 为 24 个模块创建根 `index.ts`，显式导出跨模块公开符号（非 `export *`）
- 95 个跨模块导入改为 `from '../module-name'`（通过模块根 barrel）
- Module 类不从 barrel 导出，直接从 `.module.ts` 文件导入，避免循环依赖

### 阶段 4 — `common/` 目录 barrel 整合

- 删除 14 个 `common/*/index.ts` 子目录 barrel
- 创建 `common/index.ts` 单一根 barrel，显式导出 30 个跨模块公共符号
- 192 个文件更新导入路径

### 阶段 5 — 更新 AGENTS.md 和 ESLint 规则

- 重写 AGENTS.md「Barrel Exports」章节：从「每子目录一个 barrel」改为「模块根一个 barrel」

- 清除 ESLint `no-restricted-imports` 中所有 barrel 相关 pattern

### 阶段 6 — `prisma/` 和 `llm-runtime/` barrel 对齐
