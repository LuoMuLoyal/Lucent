# 2026-07-18 迁移日志

## 修复 refresh token 接口缺少 @Public() 装饰器

### 问题

`SessionController.refresh`（`POST /api/v1/auth/refresh`）缺少 `@Public()` 装饰器。全局 `JwtAuthGuard`（`app.module.ts` 中通过 `APP_GUARD` 注册）会对所有未标记 `@Public()` 的路由执行 JWT 验证，导致 refresh 接口在 access token 过期后返回 401，形成死循环——用户无法刷新令牌，只能重新登录。

代码注释 `// No auth guard — accessToken may be expired` 与实际行为矛盾：全局守卫启用后，该接口被拦截。

### 修复

- `src/modules/auth/controllers/session.controller.ts`：
  - import `Public` 装饰器。
  - 在 `refresh` 方法上添加 `@Public()` 装饰器（方法级别，不影响同控制器中 `logout`/`sessions`/`revokeSession` 的认证要求）。
  - 注释从 `No auth guard — accessToken may be expired` 改为 `Public — accessToken may be expired, refresh uses the refreshToken body`。
- 运行 `pnpm export:openapi` 重新生成 `docs/openapi.json`：`/api/v1/auth/refresh` 不再包含 `security` 字段，与 `logout` 接口（仍需 `access-token`）形成正确对比。
