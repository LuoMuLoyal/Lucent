### `streamModelResponse` onText catch 收紧为仅传输层错误（🔴 #2）

- `src/modules/assistant/agent/runtime/model-stream.ts`
  - 新增 `isTransportError` 函数，仅放行传输层错误（`ECONNRESET`、`EPIPE`、
    `ERR_STREAM_PREMATURE_CLOSE`、`ERR_STREAM_WRITE_AFTER_END`、`ERR_HTTP_HEADERS_SENT`、
    `AbortError`），编程错误（TypeError / ReferenceError / SyntaxError）和业务逻辑错误
    继续抛出，避免回调内部 Bug 被静默掩盖。
  - catch 块日志消息增加 `(transport)` 标记以区分。

  - 新增 "rethrows non-transport errors from onText" 测试，验证 TypeError 被重抛。

### `extractMessageText` 原型链属性安全检查（🟡 #3）

- `src/modules/assistant/agent/runtime/message-text.utils.ts`
  - `'text' in part` 改为 `Object.prototype.hasOwnProperty.call(part, 'text')`，
    避免原型链属性误判。属性访问改为 `(part as Record<string, unknown>)['text']`
    满足 ESLint `no-unsafe-assignment` 规则。

### `nodes.ts` 移除不可达代码（🟡 #4）

- `src/modules/assistant/agent/runtime/nodes.ts`
  - `streamModelResponse` 返回类型为 `Promise<AIMessage>`，`response instanceof AIMessage`
    永远为 `true`，移除冗余 if/else 检查及不可达的 `stopReason: 'no_match'` 分支。
  - 移除不再使用的 `AIMessage` import，添加注释说明类型保证。

### `respond.ts` 缓存 key 防御空值（🟡 #5）

- `src/modules/assistant/agent/runtime/respond.ts`
  - `cacheable` 条件增加 `typeof state.userMessage === 'string' && state.userMessage.length > 0`
    防御，避免上游状态构造 Bug 导致 `makeShortHash(undefined)` 产生缓存污染。

### `setup-app.ts` Scalar 版本解析 catch 增加日志（🟡 #6）
