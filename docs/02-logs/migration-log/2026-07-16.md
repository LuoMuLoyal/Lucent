### E2E 测试 trustProxy 从配置读取

- `test/helpers/e2e-helpers.ts`：`createTestApp` 中 `FastifyAdapter` 的 `trustProxy` 从硬编码 `true` 改为从 `ConfigService` 读取 `${ConfigKey.App}.trustProxy`，与 `main.ts` 行为一致。移除重复的 `configService` 变量声明。

### apiReference 类型断言改用 @ts-expect-error

- `src/setup-app.ts`：`apiReference()` 返回值的 `as` 类型断言改为 `@ts-expect-error` 指令。当 `@scalar/nestjs-api-reference` 修复类型定义后，TS 编译器会因未使用的 `@ts-expect-error` 报错，提醒开发者移除指令。

### AdminJS Session 迁移验证（待手动执行）

Express→Fastify 迁移时移除了 `resave`、`saveUninitialized`、`secret`、`name` 等 session 选项，仅保留 `cookie` 选项。`@adminjs/fastify` 的 session 处理机制与 `@adminjs/express` 不同，需手动验证 session 行为：

1. `pnpm start:dev` 启动服务
2. 访问 `/admin`，使用管理员凭据登录
3. 刷新页面，确认登录状态保持
4. 等待一段时间后再次访问，确认 session 未异常过期

若发现 session 行为异常，需在 `src/admin/services/auth-router.service.ts` 的 `buildAuthenticatedRouter` 调用中补充必要的 session 配置。

### 事务外缓存失效（暂不处理）

`src/modules/daily-records/services/records.service.ts` 中 `invalidateSuggestionCache` 在事务外执行。当前 `try/catch` best-effort 实现已足够安全（缓存有 TTL 5-15 分钟，失败时仅 warn 日志），作为低优先级改进暂不处理。若后续引入更严格的缓存一致性要求再行调整。
