## 敏感操作由 Security PIN 改为密码再认证（Task 8）

将原 Security PIN 提升机制替换为密码再认证（password re-authentication），用于敏感账户/数据操作。不颁发任何 elevation token，也不维护二级 session。

### 主要变更

- 新增 `AUTH_PASSWORD_NOT_SET` Problem Code（401，`authentication` kind），用于 OAuth-only 用户尝试进行需要密码的敏感操作时提示前端先设密。
- `src/common/api/problem-catalog.ts`、`src/common/result/domain-failure.ts`：注册 `AUTH_PASSWORD_NOT_SET`。
- `src/i18n/zh-CN/common.json`、`src/i18n/en/common.json`：新增 `problem_auth_password_not_set_title` / `problem_auth_password_not_set_detail`。
- `src/modules/auth/adapters/better-auth.adapter.ts`：新增 `verifyPasswordForUser(userId, password): ResultAsync<boolean, DomainFailure>`，查询 Better Auth credential `Account` 并校验密码；无 credential 账户时返回 `AUTH_PASSWORD_NOT_SET`。
- `src/modules/auth/services/identity/rate-limit.service.ts`：新增按 `userId` 分桶的再认证限流方法（`checkReauthRateLimit` / `recordReauthFailure` / `clearReauthFailures`），复用现有登录限流窗口与阈值常量，失败达到上限时返回 `RATE_LIMITED`（携带 `retryAfter`）。
- `src/modules/auth/services/identity/password-reauth.service.ts`（新建）：`PasswordReauthService.verify(userId, password)` 串接限流检查、Better Auth 密码校验、失败计数/成功清理，统一返回 `AUTH_WRONG_PASSWORD` / `AUTH_PASSWORD_NOT_SET` / `RATE_LIMITED`。
- 敏感端点改造：
  - `POST /account/password`：DTO `oldPassword` 改名为 `password`，改密前由 `PasswordReauthService` 校验当前密码。
  - `POST /account/email`：DTO 新增 `password`，改邮箱前校验密码，再进入原有验证码流程。
  - `DELETE /account/identities/:identityId`：新增请求体 `UnlinkIdentityDto { password }`，解绑前校验密码。
  - `DELETE /account`：密码路径改由 `PasswordReauthService` 校验；保留 OAuth-only 用户的邮箱验证码删除路径。
  - `POST /user/data-export-requests`：DTO 新增必填 `password`，创建导出请求前校验密码。
- `src/modules/account/account.controller.ts`、`src/modules/data-export/data-export.controller.ts`：移除 `SecurityElevationGuard` 与 `@RequireSecurityElevation()`，改为依赖请求体内的 `password` 进行再认证。
- `src/modules/user-settings/dto/response.dto.ts`、`src/modules/user-settings/services/user-settings.service.ts`：用户设置资源用 `passwordReauthenticationRequired: true` 替代原 `securityPin` 字段，表示敏感操作现在需要密码再认证。
- `src/modules/assistant/types/ports.ts`、`src/modules/assistant/services/policy.service.spec.ts`：同步 `IAssistantUserSettings` 接口，移除 `securityPin`、新增 `passwordReauthenticationRequired`。
- 未删除 `AuthTokenService`、`security-pin` 模块及其文件（Task 9 处理）。
