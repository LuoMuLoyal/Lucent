## Better Auth 用户表合并与 NestJS Adapter（Task 2）

### Schema 变更

- `prisma/models/user.prisma`：
  - `User.email` 由 `String?` 改为 `String`（必填，`@unique` 保留）。
  - 新增 `User.emailVerified Boolean @default(false) @map("email_verified") @db.Boolean`。
  - 原 `sessions UserSession[]` 关系重命名为 `lucentSessions UserSession[]`（并指定关系名 `lucentSessions`）；新增 Better Auth 的 `sessions Session[]` 与 `accounts Account[]` 关系。
- `prisma/models/better-auth.prisma`：
  - 删除独立的 `BAUser` 模型。
  - `Session.user` / `Account.user` 外键与关系指向 `User`（`onDelete: Cascade`）。
  - `Verification` 模型保持不变。
- 运行 `pnpm prisma:generate` 与 `NODE_ENV=test pnpm exec prisma db push --accept-data-loss`，测试库 schema 已同步。

### NestJS Adapter

- 新建 `src/modules/auth/adapters/better-auth.adapter.ts`：
  - `@Injectable()` service `AuthBetterAuthAdapter`，注入 `PrismaService` 与 `ConfigService`。
  - 通过 `prismaAdapter(prisma, { provider: 'postgresql' })` 使用注入的 Prisma client。

- `src/modules/auth/auth.module.ts`：注册 `AuthBetterAuthAdapter` 并 export，不删除/替换现有 auth provider/controller/service。
- `src/config/env/environment.validation.ts`：

  - 加入 `assertProductionEnvironment` 必填列表。

## Better Auth Credential/Password 领域迁移（Task 3）

将 Lucent 手写 credential/password 流程迁移到 Better Auth 内核，同时保持现有 API facade、DTO、Problem Details、i18n、限流和 JWT access/refresh 合同不变。

### 主要变更

- `src/modules/auth/services/identity/credential.service.ts`：
  - 注册调用 `AuthBetterAuthAdapter.auth.api.signUpEmail`，仍前置 Lucent 注册验证码校验（anti-enumeration）。
  - 登录调用 `AuthBetterAuthAdapter.auth.api.signInEmail`，保留验证码登录分支。
  - 改密/设密直接读写 Better Auth `Account` 行，使用 adapter 暴露的 `hashPassword`/`verifyPassword`。

  - 新增 `databaseHooks.user.create.after`，确保 Better Auth 创建用户时同步创建 `UserProfile`。
  - 暴露 `hashPassword`、`verifyPassword`、`credentialProviderId`、`credentialIssuer`、`getEmailCallbackUrl()`。
- `src/mail/mail.service.ts` / `src/mail/templates.ts`：

- `src/modules/auth/controllers/local.controller.ts`：
  - 调整 `/auth/verify-email` 与 `/auth/forgot-password` 响应文案；保持 DTO 路径不变。
- DTO 调整：`reset-password.dto.ts`、`set-password.dto.ts`、`verify-email.dto.ts`、`send-verification-code.dto.ts` 的最小字段修正。
