## 质量修复：消除 fromPromise 中的 throw error 反模式

- 新增 `src/common/result/unknown-error.mapper.ts`：
  - `mapUnknownToInternalFailure(error, context)`：将未知异常映射为 `INTERNAL_ERROR`。
  - `mapUnknownToDependencyFailure(error, context)`：将未知异常映射为 `DEPENDENCY_UNAVAILABLE`。
- `src/common/result/index.ts`：导出上述两个 helper。
- 替换以下文件中 `fromPromise(..., (error) => { throw error; })` 反模式：
  - `src/modules/account/services/account.service.ts`
  - `src/modules/auth/adapters/better-auth.adapter.ts`
  - `src/modules/auth/services/identity/credential.service.ts`
  - `src/modules/auth/services/oauth/facade.service.ts`

  - `src/modules/auth/services/token.service.ts`
- `src/modules/auth/services/identity/credential.service.ts`：
  - 修复登录流程中 `.orElse(() => this.recordLoginFailure(email))` 把 `internal`/`dependency` 失败也折叠为 `AUTH_WRONG_PASSWORD` 的问题；现在仅业务认证失败才返回反枚举错误，基础设施失败原样传播。
