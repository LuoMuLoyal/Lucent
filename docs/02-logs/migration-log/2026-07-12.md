### JWT Token `status` 字段从可选改为必需

- **文件:** `src/modules/auth/types/auth-request.ts`、`src/modules/auth/strategies/jwt-access.strategy.ts`
- **变更:** `UserPayload.status` 从 `status?: string` 改为 `status: string`（必需字段）；`JwtAccessStrategy.validate()` 移除 "旧 token 无 status 字段时允许通过" 的兼容逻辑，改为 `status !== 'active'` 即拒绝。
- **影响:** 所有签发的 JWT 必须包含 `status` 字段。旧 token（无 `status`）将被直接拒绝，用户需要重新登录获取新 token。
- **测试:** `jwt-access.strategy.spec.ts` 移除 3 个向后兼容测试，新增 2 个 "status 为 undefined/null 时抛 UnauthorizedException" 测试；所有 controller spec 的 mock `UserPayload` 统一补充 `status: 'active'`。
