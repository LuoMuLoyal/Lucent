## Visit Summary and Product Measurement — Task 2 代码质量修复

- `getSharedSummaryByToken` 返回值收敛为类型化读模型 `ShareReadModel`（shareId/scope/selectedFields/expiresAt/revokedAt/firstAccessedAt/lastAccessedAt/accessCount），不再暴露原始实体的 `tokenHash` 与 `userId`，Task 4 响应序列化不可能泄漏哈希或属主；`accessCount` 返回记录后的视图（读时值 +1）。
- 撤销竞态关闭：访问记录由单次守卫 `updateMany({ where: { id, revokedAt: null, expiresAt: { gt } } })` 完成——读取与写入之间被撤销/过期则 `count === 0` 返回 null 且不记访问，`updateMany` 不会在行消失时抛 P2025；保留 `increment: 1` 单调用语义，首次打开写 `firstAccessedAt`、后续仅刷新 `lastAccessedAt`。
- 错误抛出改用 common barrel 的 `badRequest()` 助手（`{ code: BAD_REQUEST, message }` 信封，与 ai-summary/auth 服务一致，不再 `throw` 裸 BadRequestException）。
- 校验边界补强：非法日期（`Number.isNaN(getTime())`）拒绝，`dateFrom > dateTo` 拒绝；`selectedFields` 持久化前去重（`[...new Set()]`，保留首次出现顺序）。
- 注释补记：token 哈希唯一索引碰撞概率 ~2^-256，冲突时插入失败而非泄漏，不做重试；分享 TTL 7 天为有意区别于旧 24h 摘要缓存 TTL（持久化授权可随时撤销/过期）。
