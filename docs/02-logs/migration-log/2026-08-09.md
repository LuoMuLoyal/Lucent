## Proactive Suggestion Runtime — Task 3 bounded recompute queue

- 新增 `RecomputeQueueService`，复用共享 `BullmqQueueFactory`，以
  `suggestion-recompute:{userId}:{localDate}` 作为稳定 job ID，并用 1 秒 debounce 合并待执行 job。
  重复事件更新同一 delayed job 的最新 source version 和去重后的 reason codes；已完成/失败的保留 job
  会被移除后重新排队。
- 新增 `RecomputeTriggerListener`，覆盖 daily record、dose log、reminder、health context、settings
  和 health event 六类 domain event。监听器先读取当前 version、标记 materialization pending，再 enqueue；
  无日期事件按用户 profile timezone 解析今天，失败只记录结构化 error 日志，不向 EventEmitter 抛出异常。
- reason code 固定集合扩展为 `daily_record_changed`、`dose_log_changed`、`reminder_changed`、
  `health_context_changed`、`settings_changed`、`health_event_changed`；仍不保存健康内容 raw payload。
- Task 1 中挂在 cache listener 的重算红测已迁移到真实 trigger listener 边界；队列 worker 处理器暂为
  Task 4 的接线占位，不在本阶段伪造建议生成结果。
