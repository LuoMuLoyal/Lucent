## Task 6 medication slot runtime

- Medication collector 不再从 date-only 午夜推导当前分钟；它使用 `now()`，并在用户 profile timezone 中把 `scheduledFor + scheduledTime` 组合成真实时间点。非法 profile timezone 回退 `Asia/Shanghai`；DST gap、fold 和无效日历日期有确定处理，不伪造 overdue instant。
- collector 按 reminder slot 生成 `planned`、`taken`、`skipped`、`unconfirmed` 和 `overdueUnconfirmed` 状态；同一药品同日多个槽位独立评估，summary 同时正确统计有提醒槽位和无提醒药品。
- `MedicineDoseLogReaderPort` 的 lean fact 增加 `reminderId`。新日志按 reminderId 精确匹配；历史空 reminderId 仅在 medicine+scheduledTime 唯一时 fallback，歧义日志不套用到任一同时间槽位。
- `MissedDoseRuleService` 只消费 `overdueUnconfirmed`；legacy `pending_dose` 仍保留为兼容 signal，但不再触发漏服规则，候选 copy 使用“尚未确认”语义，并拒绝非有限或不完整 payload。
