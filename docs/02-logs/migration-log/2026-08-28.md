### S-3：logger.module.ts factory 中 new Logger 评估

- 评估结论：保持现状不变。`new Logger('VictoriaLogsTransport')` 在 `WinstonModule.forRootAsync` 的 factory 闭包中，是 DI 工厂模式的标准用法，不依赖 DI 容器生命周期。项目中统一模式是类字段 `private readonly logger = new Logger(...)`，此 factory 非类，无法用类字段。抽成 `VictoriaLogsTransportFactory` provider 会增加间接层但无实际收益（NestJS `Logger` 是全局内置 class，`inject(Logger)` 没有意义）。审查文档亦标注"优先级低"、"保持现状亦可"。
