## Prisma 7 生成客户端 internal/class.js 缺失修复 (LUC-2026-0709-16)

### 背景

- Prisma 7 `prisma-client` 生成器配置 `moduleFormat = "cjs"` 时，`generated/prisma/internal/` 目录只生成 `.ts` 文件，不生成对应 `.js` 文件。
- `client.js`（CJS 格式）运行时 `require("./internal/class.js")` 和 `require("./internal/prismaNamespace.js")`，导致 `pnpm build`、`pnpm export:openapi` 等编译运行流程报 `Cannot find module './internal/class.js'`。
- 项目已有 `scripts/dev/fix-generated-prisma-internal.js` 修复脚本（用 TypeScript `transpileModule` 将 `.ts` 编译为 `.js`），但只有 `pnpm prisma:generate` 会调用它。
- `/generated/prisma` 在 `.gitignore` 中，每次 `pnpm install` 后不会自动生成客户端，需手动运行 `pnpm prisma:generate`。

### 改动内容

- `package.json` 新增 `postinstall` 钩子：`"postinstall": "pnpm prisma:generate"`，确保每次 `pnpm install` 后自动生成 Prisma 客户端（含 `.js` 修复）。
- `package.json` 的 `export:openapi` 脚本改为 `"pnpm prisma:generate && pnpm build && ..."`，作为双重保障。

### 验证

- `pnpm export:openapi` ✅（prisma generate → fix script → nest build 545 files 0 issues → OpenAPI 87 paths 193 schemas）

## 可观测性增强

### 背景

Lucent 已有 pino 结构化日志、request-id 链路追踪、多级健康探针和全局异常结构化日志。但缺少
HTTP 响应耗时、慢请求告警、应用生命周期日志和进程级周期指标。

### 改动

1. **HTTP 请求日志增加响应耗时** — `logger.config.ts` 中 `customSuccessMessage` 利用 pino-http
   v11 直接传入的 `responseTime` 参数，输出格式从 `GET /path completed 200` 变为
   `GET /path completed 200 in 42ms`。
2. **慢请求告警拦截器** — 新建 `common/interceptors/slow-request.interceptor.ts`，全局注册于
   `setup-app.ts`。超过 `SLOW_REQUEST_THRESHOLD_MS`（默认 2000ms）的请求会触发 `warn` 日志，
   包含 method、path、durationMs、handler 类名。支持 `@SkipSlowRequestLog()` 装饰器跳过。
3. **应用生命周期日志** — 新建 `common/logger/lifecycle.service.ts`，实现 `OnApplicationBootstrap`
   和 `OnApplicationShutdown`。`main.ts` 新增 `app.enableShutdownHooks()` 以激活 SIGTERM/SIGINT
   钩子链，确保 Prisma/Redis/队列清理过程在结构化日志中留痕。
4. **进程指标周期日志** — 新建 `common/logger/process-metrics.service.ts`，每
   `METRICS_LOG_INTERVAL_MS`（默认 5 分钟）输出 rss/heapUsed/heapTotal/external/uptimeSeconds/
   activeHandles。测试环境跳过，interval 调用 `unref()` 不阻塞进程退出。
5. **新增环境变量** — `SLOW_REQUEST_THRESHOLD_MS`（10–300000ms，默认 2000）、
   `METRICS_LOG_INTERVAL_MS`（10000–3600000ms，默认 300000），均含 Joi 校验和默认值常量。
