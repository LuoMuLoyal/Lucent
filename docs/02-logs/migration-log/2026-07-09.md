## Prisma 7 生成客户端 internal/class.js 缺失修复 (LUC-2026-0709-16)

### 背景

- Prisma 7 `prisma-client` 生成器配置 `moduleFormat = "cjs"` 时，`generated/prisma/internal/` 目录只生成 `.ts` 文件，不生成对应 `.js` 文件。
- `client.js`（CJS 格式）运行时 `require("./internal/class.js")` 和 `require("./internal/prismaNamespace.js")`，导致 `pnpm build`、`pnpm export:openapi` 等编译运行流程报 `Cannot find module './internal/class.js'`。
- 项目已有 `scripts/dev/fix-generated-prisma-internal.js` 修复脚本（用 TypeScript `transpileModule` 将 `.ts` 编译为 `.js`），但只有 `pnpm prisma:generate` 会调用它。
- `/generated/prisma` 在 `.gitignore` 中，每次 `pnpm install` 后不会自动生成客户端，需手动运行 `pnpm prisma:generate`。

### 改动内容

- `package.json` 新增 `postinstall` 钩子：`"postinstall": "pnpm prisma:generate"`，确保每次 `pnpm install` 后自动生成 Prisma 客户端（含 `.js` 修复）。
- `package.json` 的 `export:openapi` 脚本改为 `"pnpm prisma:generate && pnpm build && ..."`，作为双重保障。

### 验证

- `pnpm export:openapi` ✅（prisma generate → fix script → nest build 545 files 0 issues → OpenAPI 87 paths 193 schemas）
