## Common/Queue — CronJobsService 队列分离

### 修复 1：reminder-dispatch 拆分独立队列

- **文件**: `src/common/queue/cron-jobs.service.ts`
- **变更**: 将 `reminder-dispatch`（每分钟）从共享的 `lucent-cron` 队列拆分到独立队列 `lucent-reminder-dispatch`，原队列保留 `data-retention-cleanup`（每天）和 `lifecycle-refresh`（每 5 分钟），并为原队列设置 `workerConcurrency: 2`
- **原因**: 三个任务共用单队列单 Worker（concurrency=1），高频的 `reminder-dispatch` 耗时超过 1 分钟时会阻塞 `lifecycle-refresh` 和 `data-retention-cleanup`
- **新增常量**: `REMINDER_QUEUE_NAME = 'lucent-reminder-dispatch'`

### 修复 2：新增 CronJobsService 单元测试

- **文件**: `src/common/queue/cron-jobs.service.spec.ts`（新增）
- **覆盖**: Redis 不可用跳过注册、两个队列正确创建、scheduler 注册到正确队列、processor 按 job.name 分发到对应 service、未知 job name 记录 warn、`upsertJobScheduler` 失败时记录 error
