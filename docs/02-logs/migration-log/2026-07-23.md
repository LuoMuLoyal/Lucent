## `localizeEvidenceValue` 类型修复

### 背景

`pnpm typecheck` 报错 TS2322：`SuggestionService.localizeEvidenceValue()` 中 `this.i18n.t()` 返回类型被 `tsc` 推断为 `unknown`（变量赋值丢失了泛型上下文推断），导致三元表达式 `translated === key ? value : translated` 中的 `translated` 无法赋给函数的 `string` 返回类型。

### 修复

对 `i18n.t()` 的返回值添加 `as string` 类型断言。由于 ESLint 的 `@typescript-eslint/no-unnecessary-type-assertion` 规则认为该断言多余（ESLint 推断返回类型为 `string`），添加 `eslint-disable-next-line` 注释说明 `tsc` 与 ESLint 的推断分歧。

**文件:** `src/modules/today-suggestion/services/suggestion.service.ts`

## Barrel 文件误导出 spec 文件修复

### 背景

CI 中 `pnpm export:openapi` 失败，报错 `ReferenceError: describe is not defined`。根因是 3 个 barrel 文件（`index.ts`）错误地导出了 `.spec.ts` 文件，导致 `nest build` 将 spec 文件编译到 `dist/`，运行时加载 barrel 时触发 spec 中的 `describe()` 调用（Vitest 全局变量在普通 Node.js 运行时不存在）。

### 修复

从以下 3 个 barrel 文件中移除对 `.spec` 文件的导出：

- `src/common/interceptors/index.ts` — 移除 `api-envelope.interceptor.spec`、`slow-request.interceptor.spec`
- `src/common/filters/index.ts` — 移除 `api-exception.filter.spec`
- `src/common/logger/index.ts` — 移除 `logger.config.spec`、`request-context.service.spec`
