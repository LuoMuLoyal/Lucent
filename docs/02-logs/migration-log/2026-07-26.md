## Findings 只基于有效记录生成

文件：`src/modules/reports/dashboard/presenter.service.ts`

- `buildFindings` 中，hydration finding 仅在 `waterSeries` 存在有效记录（> 0）且低于 1.5L 的天数 ≥ 4 时生成。
- medication finding 仅在 `medicationSeries` 存在有效记录且 ≥ 80% 的天数 ≥ 5 时生成。
- `dayCount` 参数由固定 7/30 改为实际有效记录天数，避免缺数据时仍生成 "7 of the last 7 days below 1.5L" 这类与趋势图空状态矛盾的结论。

## 建议历史按 locale 过滤，修复 Report 页中英文混排

来源：`../Luminous/plans/2026-07-26-report-page-refactor.md`

### 数据层

- `prisma/schema.prisma`：在 `UserSuggestion` 模型新增 `locale String?` 字段，并加 `@@index([userId, date, locale])`。
- 使用 `pnpm prisma:generate` 重新生成 Prisma client；通过 `prisma db execute --stdin` 单独执行 `ALTER TABLE ... ADD COLUMN locale` 与 `CREATE INDEX`，避免 `db push` 误删 `drugbank_passage_embeddings` / `medical_qa_embeddings` 等无关表。

### 服务层

- `src/modules/today-suggestion/services/lifecycle/service.ts`：
  - `persistActive` 新增 `locale` 参数并写入 DB。
  - `getHistory` 新增 `locale` 参数，按 `locale` 或 `null` 过滤，兼容历史无 locale 记录。
  - 新增 `normalizeLocale` 私有方法。
- `src/modules/today-suggestion/services/suggestion.service.ts`：两处 `persistActive` 调用传入当前 locale。
- `src/modules/today-suggestion/today-suggestion.controller.ts`：`GET /today/suggestions/history` 从 `accept-language` header 读取 locale 并传入 service，无 header 时回退到 `zh-CN`。

### 测试

- 更新 `src/modules/today-suggestion/services/lifecycle/service.spec.ts` 中 `persistActive` 与 `getHistory` 调用签名。
- 更新 `src/modules/today-suggestion/services/suggestion.service.spec.ts` 中 `persistActive` 断言以包含 locale。
- 更新 `src/modules/today-suggestion/today-suggestion.controller.spec.ts` 中 `getHistory` 测试，验证 locale 透传与过滤参数。

### 验证

- `pnpm lint:check` 通过
- `pnpm typecheck` 通过
- `pnpm test -- --testPathPattern="today-suggestion" --no-coverage` 通过
- 注意：之前直接用 `pnpm prisma generate` 会导致 generated client 缺失 `internal/class.js`，应使用项目脚本 `pnpm prisma:generate` 以触发修复脚本。
