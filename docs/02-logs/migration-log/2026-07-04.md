- `tsconfig.json` 删除 `"baseUrl": "."`。
- 当前仓库只通过 `paths` 维护 `#generated/*` 别名；在现有 TypeScript 基线里，这个别名解析不再需要
  `baseUrl`，保留它只会继续触发 TS 6 的过时报错提示。

### 验证

- `pnpm typecheck` ✅
- `pnpm build` ✅
